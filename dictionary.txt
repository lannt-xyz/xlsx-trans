#
#   - Mỗi dòng một từ. Chia nhóm bằng [tên nhóm] (nhóm chỉ để bạn dễ quản lý, tên tùy ý).
#   - Dòng bắt đầu bằng # là ghi chú.
#   - Từ nằm trong câu dài hơn vẫn được giữ nguyên; cả ô chỉ gồm từ trong danh sách thì không gọi model.
#   - Phân biệt hoa thường; từ dài được ưu tiên khớp trước.
#   - Đổi nội dung file này thì bản dịch cũ trong cache tự không dùng lại.

# Thêm nhanh từ dòng lệnh:   python app.py --dict-add person 山田太郎
# Xem danh sách:             python app.py --dict-list

# [screen]
# ログイン画面

# [item]
# 商品コード
